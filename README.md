# トレース表エディタ

プログラムのトレース表（ステップごとの変数の値を書き出す表）を、ブラウザ上で手早く記入できるツールです。
基本情報技術者試験の擬似言語や、授業で扱う Java のプログラムを手でたどる練習を想定しています。

- HTML ファイル 1 つだけで動作（外部ライブラリなし・通信なし）
- ダウンロードしてダブルクリックすれば、オフラインでも使えます

## デモ

GitHub Pages で公開しています。次の URL でそのまま使えます。

https://Nixe77.github.io/trace-table-editor/

## 使い方

1. `index.html` をブラウザで開く
2. 左の「コード」欄に、Java や擬似言語のコードを貼り付ける
3. 「変数を抽出」を押すと、宣言文から変数の列が自動で作られる（手動で追加・削除も可）
4. コード行の右端の **＋** を押すと、その行番号のステップが表に追加される（前の行の値は自動コピー）
5. 変化した変数の値だけを書き換えていく

前の行から値が変わったセルは自動で強調表示されます。選択中の行に対応するコード行もハイライトされます。

### コードを直接書き換える

行番号付きで表示されているコードは、**行をクリックするとその場で書き換えられます**。

| 操作 | 動き |
|---|---|
| `Enter` | 確定して次の行へ |
| `Shift + Enter` | 確定して前の行へ |
| `Esc` | 取り消し |
| `Ctrl + Enter` | 下に空行を挿入してそこを編集 |
| 空行で `Backspace` | その行を削除して 1 つ上へ |

まとめて書き換えたいときや貼り直したいときは「コードを編集」でテキスト欄を開きます。書き換え・挿入・削除は `Ctrl + Z`（表の外にフォーカスがあるとき）で元に戻せます。

自動トレースがエラーになったときは、**原因の行がコード上で赤く表示されます**。メッセージにもその行の中身が出るので、そのまま行をクリックして直せます。

## 自動トレース（擬似言語）

基本情報技術者試験 科目B の擬似言語で書いたコードは、自動で実行してトレース表を作れます。

- 自動トレース: コードを実行し、1 行実行するごとに「行番号・全変数の値・出力・備考（条件の真偽、関数の開始・戻り値）」を表に生成
- 1ステップ実行: 「次へ」で 1 行ずつ進み、実行行のハイライトと変わった値の強調で流れを追える。「この行を表に追加」で表に書き写せる
- 答え合わせ: 自分で書いた表と自動トレースを行番号で突き合わせ、違うセルを赤く表示（マウスを乗せると正しい値）。行の抜け・余りも報告
- 関数だけのコードは「呼び出し式」欄に `gcd(12, 18)` のように入力して実行。何を入れればよいか分からないときは、そのまま「自動トレース」を押すと、引数の例を入れるボタンが出ます
- 配列の先頭番号（1 / 0）、条件判定の行を表に含めるかを設定可能。無限ループは 5000 ステップで停止

対応している書き方（詳細はアプリ内の「自動トレースで使える書き方」を参照）:

- 宣言 `整数型: i, sum ← 0` / `整数型の配列: a ← {1, 2, 3}` / `大域: 整数型: g`
- 代入 `x ← 式`、配列 `a[i]`、二次元配列 `m[i, j]`、`a の末尾 に 式 を追加する`
- `if / elseif / else / endif`、`while / endwhile`、`do … while (条件)`、`for (i を 1 から n まで 1 ずつ増やす) … endfor`
- 手続・関数 `○整数型: fact(整数型: n)` と `return`、再帰
- 演算子 `＋ － × ÷ mod`、`＝ ≠ ＜ ≦ ＞ ≧`、`and or not`、`÷ … の商 / の余り`、`2 の n 乗`、`の小数点以下を切り上げた値`
- 日本語の条件 `x が y と等しい / 以下 / 以上 / より大きい / より小さい`、`n が 3 で割り切れる`、`x が 未定義`、`a の要素数`
- 出力 `x を出力する`、`x と y をこの順にコンマ区切りで出力する`、`出力(x)`

未対応: クラス・メソッド呼び出し（`obj.method()`）、8 ビット型、16 進数表記。

## Java ⇔ 擬似言語 の相互変換

Java と擬似言語を双方向に変換できます。変換ボタンは言語の選択で向きが変わります。

- 言語が `Java` → 「擬似言語に変換」
- 言語が `擬似言語` → 「Java に変換」

変換結果はダイアログに出ます。「新しい表として開く」を選べば元のコードはそのまま残ります。

### 擬似言語 → Java

そのまま `Main.java` として保存すればコンパイルできる形で出力します。授業で書いた擬似言語を Java に直すときや、答え合わせに使えます。

- `大域` → `static` フィールド、`○` の手続・関数 → `static` メソッド、主処理 → `main` の中身
- 配列の先頭番号が 1 のときは、Java の 0 始まりに合わせて要素番号を 1 引きます
- `÷` は実数除算なので `(double)` を付け、`÷ … の商` は Java の整数除算をそのまま使います
- 整数型への代入で右辺が実数になる場合は、擬似言語と同じように `(int)` で切り捨てます
- 文字列の `＝` 比較は `.equals()` になります
- ブロックの中で宣言された変数は、Java のスコープに合わせてメソッドの先頭でまとめて宣言します
- `末尾に追加する` は、配列を作り直すヘルパーメソッドを添えて再現します

`未定義` の判定（`x が 未定義`）は Java の数値型・論理型では表せないためエラーになります。

### Java → 擬似言語

擬似言語での書き方を確かめたいときに使います。配列を使うコードでは、Java に合わせて「配列の先頭番号」を自動で 0 に切り替えます。

対応している書き方（次の「Java の自動トレース」もこの範囲です）:

- 型 `int` `long` `short` `byte`→整数型、`double` `float`→実数型、`boolean`→論理型、`char`→文字型、`String`→文字列型、配列 `int[] a`→整数型の配列
- 宣言・代入、`+= -= *= /= %=`、`++ --`（単独の文のとき）
- `if / else if / else`、`while`、`do-while`、`for`、拡張 for（`for (int v : a)`）、`switch`、`return`
- `static` メソッドの定義・呼び出し・再帰。`main` の中身がそのまま主処理になり、`static` なフィールドは `大域:` になります
- 演算子 `+ - * / % == != < > <= >= && || !`、`(int)` によるキャスト、`Math.abs/max/min/pow/sqrt/floor/ceil/round`、配列の `.length`
- `System.out.println(x)` / `print(x)` → `出力(x)`、引数なしの `println()` → `改行を出力する`
- 三項演算子 `c ? a : b`（代入の右辺全体にあるときだけ if / else に展開）
- `// …` と `/* … */` のコメントは残します

Java の整数どうしの `/` は切り捨てなので、`÷ … の商` に変換します（`7 / 2` → `3`）。`switch` は if / elseif の連なりに変換します（各 case が `break` か `return` で終わっていることが必要）。

文字列の `.length()` と `.equals()` には対応しています。

未対応: `break` / `continue`（switch の break を除く）、`printf`、`charAt` など上記以外のメソッド、`new` によるオブジェクト生成、`try`、ビット演算、式の中の代入や `++`。対応外の書き方は行番号付きでエラーになります。

## Java の自動トレース

言語を `Java` にすれば、**変換しなくてもそのまま**「自動トレース」「1ステップ実行」「答え合わせ」が使えます。

表の行番号も、1ステップ実行で表示されるコードも、貼り付けた Java のものです。内部では擬似言語に直して実行し、行番号を Java の行に戻しています。実行時のエラーも Java の行番号で表示されます。

- 配列は Java に合わせて 0 始まりで固定になります（「配列の先頭番号」は選べなくなります）
- `main` がないコードは、「呼び出し式」欄に `fact(3)` のように書くと実行できます
- 変換できない書き方があると、その行番号を添えて知らせます

行の作り方は擬似言語と同じです。メソッドの開始行（引数の値が入る行）、`for` の各繰返しと終了判定、`if` / `while` の条件判定がそれぞれ 1 行になります。

## 主な機能

- 行番号付きコード表示（行クリックでその場編集、右端の ＋ でステップ追加）
- 変数名の自動抽出: Java / C 系の型付き宣言、IPA 擬似言語（`整数型: i, j`、`整数型の配列: data` など）、Python 風の代入
- 変化セルの強調表示、出力欄の強調表示
- 行の挿入・削除・移動、変数列の追加・削除・並べ替え・名前変更
- 行・列の操作とコードの書き換えは「元に戻す」で復元
- エラーの原因行をコード上で赤く表示
- 複数の問題をブラウザ内に自動保存（切り替え・複製・削除）
- 書き出し: Markdown / TSV / CSV / JSON、読み込み: JSON
- 擬似言語の自動トレース・1ステップ実行・答え合わせ
- Java の自動トレース（貼り付けた Java の行番号のままトレース表になります）
- Java ⇔ 擬似言語 の相互変換（擬似言語→Java はそのままコンパイルできる形で出力）
- 印刷・PDF 保存用のレイアウト内蔵
- ライト / ダークテーマ

## キーボード操作

- `Enter` : 下のセルへ（最終行なら新しい行を追加）
- `Shift + Enter` : 上のセルへ
- `Ctrl + Enter` : 現在の行の下に行を挿入
- `Ctrl + D` : 上のセルの値をコピー
- `Alt + ↑ / ↓` : 行を移動
- `Tab` : 右のセルへ
- `Ctrl + S` : 保存（自動保存もされます）
- `Ctrl + Z` : セルの外にフォーカスがあるとき、行・列の操作を元に戻す

## 書き出し形式

- Markdown: Obsidian やメモ用。問題名・コード・表をまとめて出力
- TSV: Excel や Word の表に貼り付ける用
- CSV: 表計算ソフト用（BOM 付き UTF-8）
- JSON: このアプリで再読み込みする用

## 保存について

データはブラウザの localStorage に自動保存されます。別の PC やブラウザには引き継がれないため、残したいトレース表は JSON で書き出して保管してください。

## 動作環境

最新版の Chrome / Edge / Firefox で動作します。

## 開発

- `node scripts/test.js` で構文チェック・擬似言語インタプリタ・両方向の変換の回帰テストを実行します（Node.js が必要。外部パッケージは不要）
- JDK が入っていれば、生成した Java を `javac` で実際にコンパイル・実行して出力を突き合わせます。無ければその部分だけ自動でスキップします
- `CLAUDE.md` に設計ルール・構造・次の予定をまとめています。Claude Code で作業するときはこれが読み込まれます
