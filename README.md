# トレース表エディタ

プログラムのトレース表（ステップごとの変数の値を書き出す表）を、ブラウザ上で手早く記入できるツールです。
基本情報技術者試験の擬似言語や、授業で扱う Java のプログラムを手でたどる練習を想定しています。

- HTML ファイル 1 つだけで動作（外部ライブラリなし・通信なし）
- ダウンロードしてダブルクリックすれば、オフラインでも使えます

## デモ

GitHub Pages を有効にすると、次の URL で使えます（`<ユーザー名>` と `<リポジトリ名>` は自分のものに置き換えてください）。

`https://<ユーザー名>.github.io/<リポジトリ名>/`

## 使い方

1. `index.html` をブラウザで開く
2. 左の「コード」欄に、Java や擬似言語のコードを貼り付ける
3. 「変数を抽出」を押すと、宣言文から変数の列が自動で作られる（手動で追加・削除も可）
4. コードの行をクリックすると、その行番号のステップが表に追加される（前の行の値は自動コピー）
5. 変化した変数の値だけを書き換えていく

前の行から値が変わったセルは自動で強調表示されます。選択中の行に対応するコード行もハイライトされます。

## 主な機能

- 行番号付きコード表示（行クリックでステップ追加）
- 変数名の自動抽出: Java / C 系の型付き宣言、IPA 擬似言語（`整数型: i, j`、`整数型の配列: data` など）、Python 風の代入
- 変化セルの強調表示、出力欄の強調表示
- 行の挿入・削除・移動、変数列の追加・削除・並べ替え・名前変更
- 行・列の操作は「元に戻す」で復元
- 複数の問題をブラウザ内に自動保存（切り替え・複製・削除）
- 書き出し: Markdown / TSV / CSV / JSON、読み込み: JSON
- 印刷・PDF 保存用のレイアウト内蔵
- ライト / ダークテーマ

## キーボード操作

- `Enter` : 下のセルへ（最終行なら新しい行を追加）
- `Shift + Enter` : 上のセルへ
- `Ctrl + Enter` : 現在の行の下に行を挿入
- `Ctrl + D` : 上のセルの値をコピー
- `Alt + ↑ / ↓` : 行を移動
- `Tab` : 右のセルへ
- `Ctrl + S` : 保存（自動保存もされます）
- `Ctrl + Z` : セルの外にフォーカスがあるとき、行・列の操作を元に戻す

## 書き出し形式

- Markdown: Obsidian やメモ用。問題名・コード・表をまとめて出力
- TSV: Excel や Word の表に貼り付ける用
- CSV: 表計算ソフト用（BOM 付き UTF-8）
- JSON: このアプリで再読み込みする用

## 保存について

データはブラウザの localStorage に自動保存されます。別の PC やブラウザには引き継がれないため、残したいトレース表は JSON で書き出して保管してください。

## 動作環境

最新版の Chrome / Edge / Firefox で動作します。
