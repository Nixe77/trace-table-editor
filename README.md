# トレース表エディタ

プログラムのトレース表（ステップごとの変数の値を書き出す表）を、ブラウザ上で手早く記入できるツールです。
基本情報技術者試験の擬似言語や、授業で扱う Java のプログラムを手でたどる練習を想定しています。

- HTML ファイル 1 つだけで動作（外部ライブラリなし・通信なし）
- ダウンロードしてダブルクリックすれば、オフラインでも使えます

## デモ

GitHub Pages で公開しています。次の URL でそのまま使えます。

https://Nixe77.github.io/trace-table-editor/

## 使い方

1. `index.html` をブラウザで開く
2. 左の「コード」欄に、Java や擬似言語のコードを貼り付ける
3. 「変数を抽出」を押すと、宣言文から変数の列が自動で作られる（手動で追加・削除も可）
4. コードの行をクリックすると、その行番号のステップが表に追加される（前の行の値は自動コピー）
5. 変化した変数の値だけを書き換えていく

前の行から値が変わったセルは自動で強調表示されます。選択中の行に対応するコード行もハイライトされます。

## 自動トレース（擬似言語）

基本情報技術者試験 科目B の擬似言語で書いたコードは、自動で実行してトレース表を作れます。

- 自動トレース: コードを実行し、1 行実行するごとに「行番号・全変数の値・出力・備考（条件の真偽、関数の開始・戻り値）」を表に生成
- 1ステップ実行: 「次へ」で 1 行ずつ進み、実行行のハイライトと変わった値の強調で流れを追える。「この行を表に追加」で表に書き写せる
- 答え合わせ: 自分で書いた表と自動トレースを行番号で突き合わせ、違うセルを赤く表示（マウスを乗せると正しい値）。行の抜け・余りも報告
- 関数だけのコードは「呼び出し式」欄に `gcd(12, 18)` のように入力して実行
- 配列の先頭番号（1 / 0）、条件判定の行を表に含めるかを設定可能。無限ループは 5000 ステップで停止

対応している書き方（詳細はアプリ内の「自動トレースで使える書き方」を参照）:

- 宣言 `整数型: i, sum ← 0` / `整数型の配列: a ← {1, 2, 3}` / `大域: 整数型: g`
- 代入 `x ← 式`、配列 `a[i]`、二次元配列 `m[i, j]`、`a の末尾 に 式 を追加する`
- `if / elseif / else / endif`、`while / endwhile`、`do … while (条件)`、`for (i を 1 から n まで 1 ずつ増やす) … endfor`
- 手続・関数 `○整数型: fact(整数型: n)` と `return`、再帰
- 演算子 `＋ － × ÷ mod`、`＝ ≠ ＜ ≦ ＞ ≧`、`and or not`、`÷ … の商 / の余り`、`2 の n 乗`、`の小数点以下を切り上げた値`
- 日本語の条件 `x が y と等しい / 以下 / 以上 / より大きい / より小さい`、`n が 3 で割り切れる`、`x が 未定義`、`a の要素数`
- 出力 `x を出力する`、`x と y をこの順にコンマ区切りで出力する`、`出力(x)`

未対応: クラス・メソッド呼び出し（`obj.method()`）、8 ビット型、16 進数表記。Java の自動トレースは今後対応予定です。

## 主な機能

- 行番号付きコード表示（行クリックでステップ追加）
- 変数名の自動抽出: Java / C 系の型付き宣言、IPA 擬似言語（`整数型: i, j`、`整数型の配列: data` など）、Python 風の代入
- 変化セルの強調表示、出力欄の強調表示
- 行の挿入・削除・移動、変数列の追加・削除・並べ替え・名前変更
- 行・列の操作は「元に戻す」で復元
- 複数の問題をブラウザ内に自動保存（切り替え・複製・削除）
- 書き出し: Markdown / TSV / CSV / JSON、読み込み: JSON
- 擬似言語の自動トレース・1ステップ実行・答え合わせ
- 印刷・PDF 保存用のレイアウト内蔵
- ライト / ダークテーマ

## キーボード操作

- `Enter` : 下のセルへ（最終行なら新しい行を追加）
- `Shift + Enter` : 上のセルへ
- `Ctrl + Enter` : 現在の行の下に行を挿入
- `Ctrl + D` : 上のセルの値をコピー
- `Alt + ↑ / ↓` : 行を移動
- `Tab` : 右のセルへ
- `Ctrl + S` : 保存（自動保存もされます）
- `Ctrl + Z` : セルの外にフォーカスがあるとき、行・列の操作を元に戻す

## 書き出し形式

- Markdown: Obsidian やメモ用。問題名・コード・表をまとめて出力
- TSV: Excel や Word の表に貼り付ける用
- CSV: 表計算ソフト用（BOM 付き UTF-8）
- JSON: このアプリで再読み込みする用

## 保存について

データはブラウザの localStorage に自動保存されます。別の PC やブラウザには引き継がれないため、残したいトレース表は JSON で書き出して保管してください。

## 動作環境

最新版の Chrome / Edge / Firefox で動作します。
