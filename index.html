    自動トレースで使える書き方（擬似言語）
    • 宣言: 整数型: i, sum ← 0　整数型の配列: a ← {1, 2, 3}　大域: 整数型: g　型は 整数型・実数型・文字列型・文字型・論理型
    • 代入: x ← 式　a[i] ← 式　m[i, j] ← 式　配列の末尾追加: a の末尾 に 式 を追加する
    • 分岐・繰返し: if / elseif / else / endif　while / endwhile　do … while (条件)　for (i を 1 から n まで 1 ずつ増やす) … endfor（減らす も可）
    • 手続・関数: ○整数型: fact(整数型: n) … return 式　関数だけのコードは「呼び出し式」欄に fact(3) のように入力
    • 演算子: ＋ － × ÷ mod　＝ ≠ ＜ ≦ ＞ ≧　and or not　x ÷ y の商　x ÷ y の余り　2 の n 乗　x の小数点以下を切り上げた値（切り捨てた／四捨五入した も可）
    • 日本語の条件: x が y と等しい／と等しくない／以下／以上／より大きい／より小さい／未満　n が 3 で割り切れる　x が 未定義　a の要素数
    • 出力: x を出力する　x と y をこの順にコンマ区切りで出力する　出力(x, y)　コメントは // … と /* … */
    • 未対応: クラス・メソッド呼び出し（obj.method()）、8ビット型、16進数表記。対応外の文は行番号付きでエラーになります
    • 行の作り方: 代入・出力・return は 1 行、if / elseif / while の条件判定は 1 行（設定で省略可）、for は繰返しごとに 1 行＋終了判定 1 行、関数の開始行は引数の値を入れた 1 行。宣言だけの行は値が入らないので行になりません
    Java ⇔ 擬似言語 の変換
    • ボタンは言語の選択で向きが変わります。Java なら「擬似言語に変換」、擬似言語 なら「Java に変換」。変換結果は「新しい表として開く」で別の表になるので、元のコードは残ります
    • 擬似言語 → Java: そのまま Main.java として保存すればコンパイルできる形で出します。配列の先頭番号が 1 のときは Java の 0 始まりに合わせて要素番号を 1 引きます。÷ は実数除算なので (double) を、… の商 は整数除算をそのまま使います。大域 は static フィールド、○ の手続・関数は static メソッド、ブロックの中の宣言は Java のスコープに合わせてメソッド先頭にまとめます。末尾に追加する は配列を作り直すヘルパーメソッドを添えます
    • Java の自動トレース: 言語を Java にすれば、変換しなくてもそのまま「自動トレース」「1ステップ実行」「答え合わせ」が使えます。表の行番号は貼り付けた Java の行番号のままです（内部で擬似言語に直して実行し、行番号を Java に戻しています）。配列は Java に合わせて 0 始まりで固定になります
    • Java → 擬似言語: 擬似言語での書き方を確かめたいときは「擬似言語に変換」を使います
    • 型: int long short byte→整数型　double float→実数型　boolean→論理型　char→文字型　String→文字列型　配列 int[] a→整数型の配列
    • 文: 宣言・代入・+= -= *= /= %=・++ --（単独の文のみ）・if / else if / else・while・do-while・for・拡張 for（for (int v : a)）・switch（各 case は break か return で終わること）・return
    • 式: + - * / % == != < > <= >= && || !　整数どうしの / は ÷ … の商 になります（Java の整数除算に合わせるため）　(int) は切り捨て　Math.abs/max/min/pow/sqrt/floor/ceil/round　配列の .length
    • メソッド: static メソッドの定義・呼び出し・再帰。main の中身がそのまま主処理になります。static なフィールドは 大域: になります
    • 出力: System.out.println(x) / print(x) → 出力(x)　引数なしの println() → 改行を出力する
    • 三項演算子 c ? a : b は、代入の右辺全体にあるときだけ if / else に展開します。// … と /* … */ のコメントは残します
    • 配列の先頭番号: Java は 0 始まりなので、配列を使うコードを変換すると設定を自動で 0 に切り替えます
    • 未対応: break / continue（switch の break を除く）、printf、charAt など .length() .equals() 以外のメソッド、new によるオブジェクト生成、try、ビット演算、式の中の代入・++。対応外は行番号付きでエラーになります
