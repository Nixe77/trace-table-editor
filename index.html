    備考:
    自動トレースで使える書き方（擬似言語）
    • 宣言: 整数型: i, sum ← 0　整数型の配列: a ← {1, 2, 3}　大域: 整数型: g　型は 整数型・実数型・文字列型・文字型・論理型
    • 代入: x ← 式　a[i] ← 式　m[i, j] ← 式　配列の末尾追加: a の末尾 に 式 を追加する
    • 分岐・繰返し: if / elseif / else / endif　while / endwhile　do … while (条件)　for (i を 1 から n まで 1 ずつ増やす) … endfor（減らす も可）
    • 手続・関数: ○整数型: fact(整数型: n) … return 式　関数だけのコードは「呼び出し式」欄に fact(3) のように入力
    • 演算子: ＋ － × ÷ mod　＝ ≠ ＜ ≦ ＞ ≧　and or not　x ÷ y の商　x ÷ y の余り　2 の n 乗　x の小数点以下を切り上げた値（切り捨てた／四捨五入した も可）
    • 日本語の条件: x が y と等しい／と等しくない／以下／以上／より大きい／より小さい／未満　n が 3 で割り切れる　x が 未定義　a の要素数
    • 出力: x を出力する　x と y をこの順にコンマ区切りで出力する　出力(x, y)　コメントは // … と /* … */
    • 未対応: クラス・メソッド呼び出し（obj.method()）、8ビット型、16進数表記。対応外の文は行番号付きでエラーになります
    • 行の作り方: 代入・出力・return は 1 行、if / elseif / while の条件判定は 1 行（設定で省略可）、for は繰返しごとに 1 行＋終了判定 1 行、関数の開始行は引数の値を入れた 1 行。宣言だけの行は値が入らないので行になりません
